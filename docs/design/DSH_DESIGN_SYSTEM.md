# Refract 设计规范（对齐 DSH）

这份规范把 DeepSeek Harness 的设计原则落到 Refract 这个桌面客户端上。所有界面改动先对照这里，再动 CSS。
规则来源：DSH 的 `dsh-client-ui-ux`（workflow / alignment / spacing / icons）与 `ui-layout`、`ui-theme`、`ui-sidebar` 三个包的说明。

## 1. 视觉基础

### 1.1 颜色（只用 token，不写死色值）

| Token | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `--bg` | `#ffffff` | `#151517` | 页面底色 |
| `--sidebar` | `#f9fafb` | `#1b1b1c` | 侧栏底色 |
| `--panel` | `#ffffff` | `#232324` | 卡片/面板 |
| `--layer-2` | `#ffffff` | `#2c2c2e` | 弹窗/浮层 |
| `--text` | `#0f1115` | `#f9fafb` | 主文字 |
| `--muted` | `#61666b` | `#cfd3d6` | 次要文字 |
| `--caption` | `#adb2b8` | `#81858c` | 说明/占位 |
| `--line` | `rgba(0,0,0,.10)` | `rgba(255,255,255,.12)` | 分隔线（0.5px） |
| `--line-strong` | `rgba(0,0,0,.16)` | `rgba(255,255,255,.20)` | 控件描边 |
| `--hover` | `rgba(38,49,72,.06)` | `rgba(255,255,255,.08)` | 悬停底 |
| `--active` | `rgba(38,49,72,.10)` | `rgba(255,255,255,.14)` | 按下底 |
| `--accent` | `#4176e6` | `#5686fe` | 主色（DSH deepseek-500 / 深色提亮） |
| `--focus` | `#4176e6` | `#7aaaff` | 焦点环 |
| `--danger` | `#ec1313` | `#f25a5a` | 错误/删除 |

规则：

- 正文对比度不低于 4.5:1；`--caption` 只用于说明文字，不承载正文。
- 禁用态用 `opacity: .45`，不换色，保证深色主题下仍可辨认。
- 同一语义只用一个 token：不要在页面里另写 `#666`、`rgba(0,0,0,.08)` 这类近似色。

### 1.2 字体与字号

| Token | 值 | 用途 |
|---|---|---|
| `--fs-11` | 11px | 角标、极简说明 |
| `--fs-12` | 12px | 行说明、次要标签、表格 |
| `--fs-13` | 13px | 列表行、控件文字、正文小号 |
| `--fs-14` | 14px | 正文、字段标签 |
| `--fs-16` | 16px | 分区标题（弹窗标题、设置组标题） |
| `--fs-20` | 20px | 页面主标题 |
| `--fs-32` | 32px | 首页品牌字 |

- 字体族沿用系统栈；代码/数据包用 `--mono`。
- 行高：正文 1.6；列表行 22px；标题 24/28px。
- 字重只用 400 / 500 / 600，不用 700 做“强调”，强调优先靠层级和间距。

### 1.3 圆角体系

| Token | 值 | 用途 |
|---|---|---|
| `--dsw-radius-xs` | 4px | 小徽标、内嵌小块 |
| `--dsw-radius-sm` | 8px | 按钮、输入框、选择器、菜单项 |
| `--dsw-radius-md` | 12px | 卡片、代码块、图片、分组容器 |
| `--dsw-radius-lg` | 16px | 大面板（右栏、抽屉） |
| `--dsw-radius-xl` | 20px | 特殊浮层 |
| `--dsw-radius-panel` | 28px | 主弹窗 |

- 只允许以上六档；`50%` 仅用于圆点/头像，`999px` 仅用于胶囊标签。
- 嵌套时子级圆角 ≤ 父级，或子级贴边（父级有内边距时才允许同级圆角）。
- 相邻两块不叠双层描边：靠 `border-right` 或 0.5px `--line` 二选一。

### 1.4 阴影与层级

- 浮层：`0 0 0 .5px var(--line-strong), 0 3px 8px rgba(0,0,0,.04), 0 0 20px rgba(0,0,0,.05)`。
- 页面内卡片不用阴影，用 0.5px 描边 + 背景差。
- `z-index` 只许三层：内容 0、浮层 50、弹窗 100。

## 2. 间距

固定尺：`--sp-1..--sp-8` = 4 / 8 / 12 / 16 / 20 / 24 / 32 / 40。

- 组件内部：4 / 8（图标与文字 6–8，控件左右 10–12）。
- 相邻组件：12 / 16。
- 模块之间：24 / 32。
- 页面边缘：24（窄窗口 16）。
- 判定标准是渲染后的视觉间隙，不是 CSS margin 数字；标题离自己内容要近于离上一组。

## 3. 对齐

- 左边缘：导航文字、列表标题、字段标签、正文共用一条左轴（侧栏 12px 内缩，内容区 24px）。
- 垂直中心：单行图标+文字按视觉中心对齐，控件整体高度保持稳定。
- 两端：标题行左侧贴内容边、右侧贴尾部边。
- 重复列：多行列表的同一列（时间、状态、操作）必须共用中心或边缘。
- 图标与文字之间用固定 6px 或 8px，不允许每个组件各写一个值。

## 4. 图标

图标统一取自 DSH 官方 artwork（MIT，见 `docs/design/ICON_MAP.md`），不自行绘制：

- viewBox `0 0 16 16`，描边 1px（regular）/ 1.3px（medium）；渲染尺寸只用 **14 / 16**。
- 颜色继承 `currentColor`；图标按钮 28×28 命中区、图标 16。
- 同一语义只能一个图标；新增先查映射表。


- 统一用 1.6–1.8 描边的线性 SVG，尺寸 14 / 16 / 18 三档。
- 工具栏图标按钮 ≥ 28×28 命中区，图标本身 16。
- 图标按钮必须有 `aria-label` 或 Tooltip。
- 不用 Emoji 当功能图标；同一功能在所有页面用同一个图标。

## 5. 动效

- 只允许 `--ds-transition-duration`（0.2s）和 `--ds-transition-duration-fast`（0.1s）。
- 属性限于 `background-color`、`border-color`、`color`、`opacity`、`transform`。
- 弹窗出现用 160ms 的 scale+fade，不做大幅位移。

## 6. 主题

- 浅色/深色都由 token 驱动；新增颜色必须先加 token，再在 `html[data-ds-dark-theme]` 里给深色值。
- 切换主题不允许触发布局变化（不随主题改字号/边距）。
- 主题变量只放在 `:root` 与 `html[data-ds-dark-theme]` 两处，页面里不出现条件分支。

## 7. 禁止事项

- 不新增与尺表冲突的字号、圆角、间距数值。
- 不用绝对定位拼页面结构。
- 不用连续覆盖规则修样式（`!important`、层层覆盖），优先改源规则。
- 不为同一功能重复造组件。
