# WSift 布局与空间分配规范

参照 DSH 的 `ui-layout` 与 `ui-sidebar`：侧栏固定、主内容有最小宽度、辅助面板按优先级让位，弹窗/菜单不出可视区。

## 1. 窗口

| 项 | 值 | 说明 |
|---|---|---|
| 默认尺寸 | 1200 × 800 | 首次启动 |
| 最小尺寸 | 900 × 600 | `minWidth/minHeight`，低于此不缩放 |
| 顶部安全区 | 48px | macOS 红绿灯，侧栏顶部留白 |

窗口缩小时：先压缩辅助面板（右侧预览），再收窄内容留白（24→16），最后才允许横向滚动；不允许组件互相覆盖。

## 2. 三栏骨架

```
┌──────────────┬───────────────────────────────────────┬──────────────┐
│ 侧栏 280px    │ 主工作区 min 560px                    │ 右栏（可选）  │
│ 固定不缩放     │ 内容列 max 760px，居中于可用宽度        │ 360px，可关   │
└──────────────┴───────────────────────────────────────┴──────────────┘
```

- **侧栏**：`280px` 固定宽（`flex: 0 0 280px`），内部左右 8px、顶部 48px。折叠态宽 64px，只留图标，折叠前后不改变主内容起始基线以外的任何尺寸。
- **主工作区**：最小可用宽 560px；内容列 `max-width: 760px`，左右留白 24px（<1100px 时 16px）。超宽屏不无限拉宽输入框。
- **右栏**：仅预览类面板使用，宽 360px；`主宽 < 1040px` 时自动收起，不挤压表单。
- 两栏之间用 0.5px `--line` 分隔，不再叠卡片描边。

## 2.1 内容列（所有页面共用）

- 内容列宽 **760px**，`margin: 0 auto`，左右内边距 **8px**，顶部 **4px**。
- 报告页、设置页共用这一列；测试页/模板页是工具型分栏，左边缘对齐内容区起点（308px @1280）。
- 任何页面都不得单独改内容列宽度或左右内边距；要改就改这一条规则。

## 3. 页面内分区

- 页面标题区：标题 20px/600 + 右侧操作按钮组（按钮高度 32），底边距 16。
- 表单区：字段标签 14px，控件高 28（大控件 32），字段间距 16，分组间距 32。
- 列表区：行高 22，行内左对齐文字 + 尾部操作，行间距 0（靠背景 hover 区分）。
- 底部状态条：高 22，文字 12px `--muted`。

## 4. 弹窗

- 主弹窗（提交/登录）：宽度 `min(620px, 92vw)`，最大高度 `86vh`，超出时内容区滚动、头尾固定。
- 弹窗内边距 20；标题 16/600；底部操作右对齐，间距 8。
- 遮罩 `--mask`，点击遮罩关闭（除非有未保存输入，此时提示）。
- 弹窗必须做边界检测：距视口四周 ≥ 16px。
- Escape 关闭；焦点进入时落在第一个输入框。

## 5. 菜单与浮层

- 设置菜单：宽 220，最大高 `min(420px, 70vh)`，超出滚动；出现在触发元素上方/下方取决于剩余空间，距视口边缘 ≥ 8px。
- 下拉选择器：高度 28，菜单项高 28，菜单最大高 280。
- Tooltip：最大宽 260，8px 偏移，不遮挡被说明元素。

## 6. 滚动

- 只允许「内容区」滚动，侧栏与工具栏固定。
- 滚动条宽 10（WebKit），圆角 999，颜色 `--scroll`，hover `--scroll-hover`。
- 滚动容器必须有 `overscroll-behavior: contain`，避免带动外层。

## 7. 响应式断点

| 宽度 | 变化 |
|---|---|
| ≥ 1200 | 标准三栏/两栏 |
| 1040–1199 | 收起右栏，内容列仍 760 |
| 900–1039 | 内容留白 16，表单控件满宽，按钮组允许换行 |
| < 900 | 不出现（窗口最小 900） |

断点内只允许调整间距与列宽，不允许改变字号层级、圆角与控件高度。
