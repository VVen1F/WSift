# Refract 组件与交互规范

所有组件必须有完整状态：default / hover / focus / active / selected / disabled / loading / success / error。缺状态的控件视为未完成。

## 1. 按钮

| 变体 | 高度 | 内边距 | 圆角 | 背景 | 文字 |
|---|---|---|---|---|---|
| 主按钮 `.btn.pri` | 28（大 32） | 0 12 | `sm` | `--accent` | `--on-accent` 13px/500 |
| 次按钮 `.btn` | 28 | 0 12 | `sm` | `--panel` + 0.5px `--line-strong` | `--text` 13px |
| 幽灵 `.btn.ghost` | 28 | 0 8 | `sm` | 透明，hover `--hover` | `--muted` 13px |
| 图标按钮 `.icon-btn` | 28×28 | 0 | `sm` | 透明，hover `--hover` | 图标 16 |
| 危险 `.btn.danger` | 28 | 0 12 | `sm` | 透明，hover `--danger` 10% | `--danger` |

- 相邻按钮间距 8；按钮组与文字间距 12。
- 禁用：`opacity: .45` + `cursor: not-allowed`，不隐藏。
- 加载：按钮内文字换成「进行中…」或前置 12px spinner，宽度保持不跳动（预留最小宽）。

## 2. 输入类

- 输入框/选择器/文本域统一：高 28（多行自适应），圆角 `sm`，边框 0.5px `--line-strong`，背景 `--panel`，文字 13px，内边距 0 10。
- 焦点：边框 `--focus` + 2px `--focus` 12% 外环；不改变尺寸。
- 占位文字 `--caption`；错误态边框 `--danger`，下方 12px 错误说明。
- 字段结构：标签（14px，上）→ 控件 → 说明（12px `--caption`，下 4px）。说明文字只在需要时出现。

## 3. 列表行

- 行高 22（带描述的行 40），左右内边距 8，圆角 `sm`。
- hover `--hover`；选中 `--active` + 左侧 2px `--accent` 竖条。
- 行内列：主文字（13px `--text`）→ 次要（12px `--muted`）→ 尾操作（图标按钮 28）。
- 重复列共用对齐轴：状态列固定宽 72，时间列固定宽 96，操作列右对齐。

## 4. 开关与选择

- 开关尺寸 36×20，圆角 999，开态 `--accent`，关态 `--line-strong`；切换无位移。
- 分段选择（外观三选一）：容器 0.5px 描边，选中项背景 `--panel` + 500 字重，圆角 `sm`。

## 5. 反馈

| 类型 | 用途 | 规格 |
|---|---|---|
| Toast | 短暂成功/失败 | 底部居中，`--toast-bg`，高 32，圆角 `sm`，2.4s 自动消失，同时只显示一条 |
| Inline Notice | 需要立刻处理的局部错误 | 控件下方 12px 红字，或区块内 0.5px `--danger` 描边条 |
| Empty State | 真的没有数据 | 居中，图标 24 + 12px 说明，上下 32 间距 |
| Loading | 列表/页面 | 列表用骨架行（3 行，22 高，`--hover` 底），页面用 16px spinner |

- 不允许点击后无反馈：异步操作必须立刻给出 loading，失败必须给出原因。
- 错误文案：说清「哪一步失败 + 平台/系统原话 + 建议动作」，不只写「失败」。

## 6. 弹窗 / 菜单 / Tooltip

- 弹窗：宽 `min(620px, 92vw)`，头（标题 16/600 + 关闭 16）、体（滚动）、脚（右对齐按钮）。
- 打开时焦点进第一个可交互元素；Escape 关闭；遮罩点击关闭。
- 菜单：外部点击关闭、边界翻转、键盘上下选择。
- Tooltip：hover 300ms 出现，仅图标按钮需要。

## 7. 图标

- 线性 SVG，stroke 1.7，尺寸 14/16/18，`currentColor`。
- 语义固定：发送=箭头、截图=相机/方块、删除=垃圾桶、复制=双层方块、设置=齿轮。
- 不使用 Emoji 作为功能图标。

## 8. 状态清单（改组件前自查）

- [ ] 默认 / 悬停 / 焦点 / 按下 / 选中 / 禁用 都有样式
- [ ] 加载态不改变布局尺寸
- [ ] 错误态有文案，不是只变色
- [ ] 深色浅色都检查过
- [ ] 窄窗口下文字不溢出、操作可点到
