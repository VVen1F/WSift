## 3. 本轮改动

### 3.1 设计 Token

在 `renderer/style.css` 的 `:root` 增加三组尺：

- 间距：`--sp-1..--sp-8`（4/8/12/16/20/24/32/40）
- 字号：`--fs-11/12/13/14/16/20/32`
- 控件高度：`--h-ctl: 28px`、`--h-ctl-lg: 32px`、`--h-row: 22px`

### 3.2 圆角归一

清除 `border-radius` 的裸数值（10px ×10、8px ×8、12px ×3、6px ×2、4px ×1），全部换成 `--dsw-radius-*` 六档；保留的裸值是结构性的 `50%`（圆点）、`999px`（胶囊）、品牌点 `7px/2px`。

### 3.3 文档

- `docs/design/DSH_DESIGN_SYSTEM.md`
- `docs/design/DSH_LAYOUT_RULES.md`
- `docs/design/DSH_COMPONENT_RULES.md`

### 3.4 控件几何归一（本轮）

- 按钮：高 36 → **32**，字号 14 → 13，左右内边距 14 → 12，圆角 12 → 8；小按钮 26 → 28。
- 输入框/选择器/文本域：圆角 12 → 8，与按钮同档；高度保持 32。
- 侧栏导航：圆角 12 → 8，图标 15 → 16，图标与文字间距 6 → 8。
- 依据：控件统一 32 高 + `--dsw-radius-sm`，卡片/代码块才用 `md`，避免同屏出现两套控制几何。

### 3.5 弹窗交互（本轮）

- 提交框打开后焦点落在第一个输入框（`lsFocusSubmit`，任何入口都生效）。
- 提交框支持 Escape 关闭；正在提交（按钮 disabled）时不关闭，避免半途丢状态。
- e2e 增加两条断言：焦点必须是可编辑元素、Escape 必须关闭。

### 3.6 菜单与可读性（本轮）

- 设置菜单：加 `max-height: min(420px, 70vh)` + 内部滚动 + `overscroll-behavior: contain`，条目不外溢；菜单项字号 14 → 13，与导航一致。
- 任务列表：`overflow-x: hidden`，去掉侧栏列表底部的横向滚动条（行内容不该产生横向溢出）。
- 对比度：浅色主题 `--caption` 原为 `#adb2b8`，白底仅 **2.13:1**，改为 `#6f7479`（白底 4.72:1 / 侧栏底 4.52:1），达到 AA；深色 `--caption` 实测 4.92:1、`--muted` 12.11:1，保持不动。

### 3.7 浮层边界与横向溢出（本轮）

- 新增 `fitPop()`：浮层默认向上弹，上方放不下时自动翻到下方；1280×900 与 900×620 实测 rect 均在视口内（top/bottom = 586/836、306/556）。
- 账号管理区块 `.ls-accounts` 由固定 500px 改为可收缩（`flex: 1 1 auto; min-width: 0; max-width: 500px`），标签列 210 → 168。
  修前 `#sect-leishen` 内容宽 722 > 容器 680，1600 宽窗口底部出现横向滚动条；修后各分区 `scrollWidth == clientWidth`，横条消失。
- 全页面横向溢出扫描：设置七个分区逐一对比 `scrollWidth/clientWidth`，现在全部干净。

### 3.8 字号与控件高度扫描（本轮）

用真窗口逐元素读 `getComputedStyle`，把渲染出来的字号和高度排了序：

- 任务行：标题 14 → **13**（列表行统一 13），时间保持 12；修完 34 行标题全部 13px。
- 「清空」按钮：25px → **28px**，与其它控件同高。
- 归档行按钮：26 → **28**，内边距对齐 `.btn.sm`。
- 控件高度现状：导航/按钮/输入 32、工具栏与图标按钮 28、文本域自适应、标题输入 36（唯一的展示型大控件，已在组件规范里单独标注）。

弹窗截图：用假平台把两个账号真登录后，截了提交弹窗（浅色/深色）与登录弹窗，
确认 3 列选择行、只读项目 ID、验证码行、底部操作区都对齐；弹窗宽度 620、内边距 20、圆角 28 与规范一致。

### 3.9 模板页对齐（本轮）

- 模板页左栏标题与列表行左边缘相差 10px（标题贴容器边、列表有 10px 内缩），现在标题跟着列表对齐。
- 实测：标题 rect.left 308，列表 308，空态文字 318（内缩 10），三者关系一致。
