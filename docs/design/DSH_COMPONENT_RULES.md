# WSift 组件与交互规范

所有组件必须有完整状态：default / hover / focus / active / selected / disabled / loading / success / error。缺状态的控件视为未完成。

## 1. 按钮

| 变体 | 高度 | 内边距 | 圆角 | 背景 | 文字 |
|---|---|---|---|---|---|
| 主按钮 `.btn.pri` | 28（大 32） | 0 12 | `sm` | `--accent` | `--on-accent` 13px/500 |
| 次按钮 `.btn` | 28 | 0 12 | `sm` | `--panel` + 0.5px `--line-strong` | `--text` 13px |
| 幽灵 `.btn.ghost` | 28 | 0 8 | `sm` | 透明，hover `--hover` | `--muted` 13px |
| 图标按钮 `.icon-btn` | 28×28 | 0 | `sm` | 透明，hover `--hover` | 图标 16 |
| 危险 `.btn.danger` | 28 | 0 12 | `sm` | 透明，hover `--danger` 10% | `--danger` |

- 相邻按钮间距 8；按钮组与文字间距 12。
- 禁用：`opacity: .45` + `cursor: not-allowed`，不隐藏。
- 加载：按钮内文字换成「进行中…」或前置 12px spinner，宽度保持不跳动（预留最小宽）。

## 2. 输入类

- 输入框/选择器/文本域统一：高 28（多行自适应），圆角 `sm`，边框 0.5px `--line-strong`，背景 `--panel`，文字 13px，内边距 0 10。
- 焦点：边框 `--focus` + 2px `--focus` 12% 外环；不改变尺寸。
- 占位文字 `--caption`；错误态边框 `--danger`，下方 12px 错误说明。
- 字段结构：标签（14px，上）→ 控件 → 说明（12px `--caption`，下 4px）。说明文字只在需要时出现。

## 3. 列表行

- 行高 22（带描述的行 40），左右内边距 8，圆角 `sm`。
- hover `--hover`；选中 `--active` + 左侧 2px `--accent` 竖条。
- 行内列：主文字（13px `--text`）→ 次要（12px `--muted`）→ 尾操作（图标按钮 28）。
- 重复列共用对齐轴：状态列固定宽 72，时间列固定宽 96，操作列右对齐。

## 4. 开关与选择

- 开关尺寸 36×22（滑块 18），圆角 999，开态 `--accent`，关态 `--line-strong`；切换无位移。
- 分段选择（外观三选一）：容器 0.5px 描边，选中项背景 `--panel` + 500 字重，圆角 `sm`。

## 5. 反馈

| 类型 | 用途 | 规格 |
|---|---|---|
| Toast | 短暂成功/失败 | 底部居中，`--toast-bg`，高 32，圆角 `sm`，2.4s 自动消失，同时只显示一条 |
| Inline Notice | 需要立刻处理的局部错误 | 控件下方 12px 红字，或区块内 0.5px `--danger` 描边条 |
| Empty State | 真的没有数据 | 居中，图标 24 + 12px 说明，上下 32 间距 |
| Loading | 列表/页面 | 列表用骨架行（3 行，22 高，`--hover` 底），页面用 16px spinner |

- 不允许点击后无反馈：异步操作必须立刻给出 loading，失败必须给出原因。
- 错误文案：说清「哪一步失败 + 平台/系统原话 + 建议动作」，不只写「失败」。

## 6. 弹窗 / 菜单 / Tooltip

- 弹窗：宽 `min(620px, 92vw)`，头（标题 16/600 + 关闭 16）、体（滚动）、脚（右对齐按钮）。
- 打开时焦点进第一个可交互元素；Escape 关闭；遮罩点击关闭。
- 菜单：外部点击关闭、边界翻转、键盘上下选择。
- Tooltip：hover 300ms 出现，仅图标按钮需要。

## 7. 工作区导航行（侧栏）

### 状态模型

选中、展开、Hover 是三个独立状态，互不派生：

| 状态 | 判定 | 行背景 | 文件夹图标 | 展开箭头 |
|---|---|---|---|---|
| 折叠 · 未选中 | `!open && !sel` | 透明 | `--muted` 中性灰 | 隐藏（保留 12px 槽位） |
| 展开 · 未选中 | `open && !sel` | 透明 | **`--brand-primary`** | 显示 |
| 展开 · 会话被选中 | `open && !sel && task.on` | 透明（子行才有选中底色） | `--brand-primary` | 显示 |
| 展开 · 文件夹被选中 | `open && sel` | `--sel-bg` | `--brand-primary` | 显示 |
| 折叠 · 文件夹被选中 | `!open && sel` | `--sel-bg` | `--brand-primary` | 显示 |
| Hover | `:hover` | `--hover` | `--text`（加深） | 显示 |

- `TASKS.focus` 只有一个值：`'task'` 或 `'ws'`。点会话 → `task`，点文件夹 → `ws`，新建任务 → `task`。
- 会话行高亮条件：报告页可见 **且** `t.id === TASKS.id` **且** `focus !== 'ws'`。父文件夹不因会话选中而变色。
- `--sel-bg`：浅色 `#EAF1FF`（= `--brand-subtle`），深色 `rgba(91,141,246,.16)`。侧栏导航的当前页高亮也用同一个 token。
- 文件夹与第一个会话之间 `margin-top: 6px`；会话行左边距 16px。

状态矩阵（验收用）：

| 文件夹 | 会话 | 预期 |
|---|---|---|
| 折叠 | 无选中 | 默认样式，图标灰 |
| 展开 | 无选中 | 图标蓝，行背景透明 |
| 展开 | 子会话选中 | 只有子会话有 `--sel-bg` |
| 展开 | 文件夹选中 | 只有文件夹有 `--sel-bg` |
| 展开 | 子会话 Hover | 只有该会话变 `--hover` |
| 展开 | 文件夹 Hover | 只有该文件夹变 `--hover` |
| 折叠 | 文件夹选中 | 文件夹单独有 `--sel-bg` |

### 视觉细节点

| 状态 | 展开箭头 | 文件夹 | 加号 |
|---|---|---|---|
| 默认（未选中） | 隐藏（占位保留 12px） | 合上 `folder-close` | 隐藏 |
| Hover | 显示 | 按当前展开状态 | 显示 |
| 选中 | 显示 | 按当前展开状态 | 显示 |
| 选中且折叠 | 显示，旋转 -90° | `folder-close` | 显示 |
| 没有子项 | 完全不显示（`visibility: hidden`） | 按状态 | 显示 |

- 箭头位置始终占 12px，隐藏时用 `opacity: 0`，文字与图标不会横向跳动。
- 箭头旋转用 `transform`，不换字符。
- 点击整行 = 选中；再次点击已选中的行 = 展开/折叠（保持原有逻辑）。

## 8. 设置页结构

```
#page-settings .narrow          760px 内容列，居中
  .settings                     左右 8px，顶部 4px
    .sect                       每个分类一个，padding 0
      h3                        分类标题，14/500，下边距 12
      .klist > .krow            设置项：标签 14 / 说明 12 / 右侧控件 32，上下 18px，底部分隔线 0.5px
      .theme-group              分组模块：标题 14 / 内容，上下 18px，底部分隔线
```

- 所有分类共用同一容器，**不做垂直居中**，第一个模块永远从同一 Y 开始。
- 模块数量不影响顶部锚点；内容多了只向下滚动。
- 新加设置分类时直接复用 `.sect` + `.klist` + `.krow`，不要再写新的行样式或另加 padding。

## 9. 弹窗内缩

- 标题、副标题、表单、底部按钮统一 **24px** 左右内缩（`.modal-head` / `.modal-sub` / `.ls-card .ls-form` / `.row.actions` 都是 24）。
- 注意 `.modal-card .form { padding: 0 }` 的特异性高于 `.ls-form`，加内缩时要用 `.ls-card .ls-form`。
- 关闭按钮 28×28、图标 16（`close-outline`），不是 `×` 字符。
- 表单区独立滚动，底部按钮固定；弹窗最大高 `calc(100vh - 40px)`。

## 10. 图标

- 线性 SVG，stroke 1.7，尺寸 14/16/18，`currentColor`。
- 语义固定：发送=箭头、截图=相机/方块、删除=垃圾桶、复制=双层方块、设置=齿轮。
- 不使用 Emoji 作为功能图标。
